# Dilo — descargas

Traductor **inglés ⇄ español** para Windows 10/11 (64 bits).

## Instalar

1. Ve a [Releases](https://github.com/Grawkles/Dilo-releases/releases/latest) y descarga `Dilo-Setup-x.y.z.msi`.
2. Ábrelo. Si Windows muestra «Windows protegió tu PC», pulsa **Más información → Ejecutar de todas formas** (el instalador no está firmado).
3. No hace falta instalar nada más: Dilo lleva todo lo necesario dentro.

## Actualizar

Dilo busca versiones nuevas aquí mismo. Abajo a la derecha: **Buscar actualizaciones** → **Actualizar a vX.Y.Z**. Se descarga, se instala y se vuelve a abrir sola.

Este repositorio solo contiene los instaladores.
